# ai-todo-demo · 备用仓库

这是「2 小时 FDE 一对一带练」课的兜底仓库：课上要做出来的待办 Demo，已经做好、跑通。学员任何一步卡住超过 5 分钟，就切到这里继续后面的流程，不让环境问题吃掉课时。

## 里面有什么

和课上参考 Prompt 的范围完全一致：

- 输入框 + 添加按钮新建待办，输入为空时不能添加
- 复选框标记完成 / 取消完成
- 删除按钮
- 数据存在浏览器 localStorage，刷新不丢失

技术栈：Vite + React + Tailwind CSS v4（`@tailwindcss/vite` 插件）。没有后端、数据库和接口。

`.devcontainer` 让 Codespace 打开时自动安装依赖、启动开发服务器，并在 5173 端口打开预览，学员什么命令都不用敲。

## 课上怎么切过来

| 卡在哪 | 怎么切 |
| --- | --- |
| 动手 1：建仓库或开 Codespace 失败 | 学员打开本仓库页面，点「Use this template」→「Create a new repository」，名字填 `ai-todo-demo`，然后在新仓库里开 Codespace |
| 动手 2：AI 生成失败，修了 2 次还不行 | 同上，用模板建一个新仓库（或在原仓库里删掉生成的文件，换成本仓库的文件），从「动手 3 · 验收」继续 |
| 预览始终打不开 | 在新 Codespace 里等自动启动完成；没有自动打开就去底部「端口」面板，5173 那一行点地球图标 |

切过来以后，验收、大白话微调、分享链接、接住加需求、提交推送这些环节照常进行：后半节课练的是 FDE 的判断，不依赖代码是谁生成的。

## 导师课前自查

1. 在本仓库开一个 Codespace，确认能自动启动并看到待办页面。
2. 用课上的参考 Prompt，在一个空仓库里让 Copilot（Agent 模式）完整跑一遍。工具更新后措辞可能需要微调。
3. 课后停掉 Codespace，节省免费额度。

## 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:5173 。
